
# CarWise — Smart Car Finder

CarWise is a Python and Streamlit application that helps users find suitable cars based on their budget, preferences, and estimated ownership costs.

## 🚀 Live Demo

**Try CarWise online:** [Open CarWise Smart Car Finder](https://carwise-smart-car-finder-lkddnzcgcbqbqvkjjq6bdf.streamlit.app/)

## ✨ Features

- 🚗 Personalized car recommendations
- 📊 Side-by-side car comparison
- 💰 Budget planner and affordability analysis
- 🧮 Estimated ownership costs
- ⭐ Smart Ownership Score
- 🚘 Car catalogue and specifications
- 📥 Downloadable CSV reports
- 📄 Downloadable PDF recommendation reports
- 🎯 Recommendation matching scores

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- ReportLab

## 💻 Run Locally

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the application:

   ```bash
   python -m streamlit run app.py
   ```
